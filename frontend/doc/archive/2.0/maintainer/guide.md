## 界面操作速览

页面顶部有三个 tab：**添加 / 求解 / 文档**。

### 添加对象

- **类型下拉**：选择要添加的对象类型——未知数 / 点 / 条件
- **未知数**：输入名字，并限定取值范围（实数 / 正数 / 非负 / 负数 / 非正 / 非零）
- **点**：输入点名（单个大写字母），在 x / y / 直线 1 / 直线 2 中**恰好填写 2 项**：
  - x + y：指定坐标，如 `A(2, 3)`；填 `x` / `y` 表示该坐标是未知数，会自动创建 `x_A`、`y_A`
  - x + 直线：点在直线上且横坐标已知
  - 直线 1 + 直线 2：两条直线的交点
- **条件**：选择条件类型并填写参与的对象，详见下表

右侧**对象列表**实时显示已添加的未知数、点与条件（LaTeX 渲染）。

#### 条件类型

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| 表达式等式 | 两个表达式相等 | `2a = 6` |
| 平行 | 两直线平行 | `AB ∥ CD` |
| 垂直 | 两直线垂直 | `AB ⟂ CD` |
| 全等 | 两三角形全等 | `△ABC ≅ △DEF` |
| 相似 | 两三角形相似 | `△ABC ~ △DEF` |
| 平行四边形 / 菱形 / 矩形 / 正方形 / 等边三角形 | 快速添加特殊图形 | — |

### 求解

切到「求解」tab，输入目标表达式（记号见下文），点击启动。结果以 LaTeX 显示：

- 符号解优先，二次以内给出精确解（`a+b√c` 形式）
- 符号解求不出时自动数值求解，结果标注 `≈`（近似）

### 删除与重置

- 在「添加」页右侧选择要删除的对象；若它被其他对象依赖，会提示依赖关系
- **重置计算器**：右上角菜单 ☰ → 重置计算器，一键清空所有对象

### 数据保存

操作历史自动保存在浏览器本地（localStorage），刷新页面或重新打开后自动恢复现场，无需手动保存。

## 未知数

未知数名可以是：

- 一个小写英文字母（除 `x`, `y` 外）
- 一个希腊字母的英文拼写（除 `pi` 外）

## 点

点名需要是一个大写英文字母，不支持上下标。~~（应该没有哪道题需要用到超过 26 个点吧）~~

## 表达式

我们的表达式解析器由计算引擎实现：引擎用 TypeScript 编写，编译为浏览器原生 JavaScript（ESM）后运行，无外部依赖。

### 运算

|    代码     |   含义   |
| :---------: | :------: |
|     `+`     |    加    |
|     `-`     |    减    |
|     `*`     |    乘    |
|     `/`     |    除    |
|    `dot`    | 向量点乘 |
| `^` 或 `**` |    幂    |

注意：乘号不能省略。

### 常量和函数

|  代码  | 含义  |
| :----: | :---: |
|  `pi`  | $\pi$ |
| `sqrt` | 根号  |
| `sin`  | 正弦  |
| `cos`  | 余弦  |
| `tan`  | 正切  |
| `acos` | 反余弦 |

注意：函数必须加括号调用。

- ❌ 错误示范：`sin pi`
- ✅️ 正确示范：`sin(pi)`

### 访问未知数

直接输入你在添加它们时的名字即可。

例如：`a`、`alpha`

### 访问点坐标

格式：x / y + 点名称

例如：`xA` 代表 $x_A$

### 线段长度

直接写线段名即可。

例如：`AB` 代表 $AB$

### 角

格式：ang + 确定角的三个点

例如：`angABC` 代表 $\angle ABC$

#### 角度制

用 `deg` 代表 $^{\circ}$

例如：`30 deg` 代表 $30^{\circ}$

### 向量

#### 有向线段表示的向量

格式：vec + 起点 + 终点

例如：`vecAB` 代表 $\overrightarrow{AB}$

#### 坐标表示的向量

格式：(x 分量, y 分量)

例如：`(114, 514)` 代表 $(114, 514)$

### 三角形面积

格式：St + 三角形三个点

例如：`StABC` 代表 $S_{\triangle ABC}$

### 直线的斜率 ($k$) 和截距 ($b$)

格式：k / b + 直线名

例如：`kAB` 代表直线 $AB$ 的斜率 $k_{AB}$

注意：你必须保证这条直线不可能是竖直的

### 点到直线距离

格式：d + 点名 + t + 直线名

例如：`dAtBC` 代表点 A 到直线 BC 的距离，记作 $d_{A\text{ 到 }BC}$

## FAQ

### 如何表示圆、抛物线等图形？

研究这些图形，本质上是在研究上面的点。你可以把一个点的横纵坐标用一定的关系关联起来，例如 $x_A^2 + y_A^2 = 1$
或 $y_A = 11 x_A^2 + 45 x_A + 14$。对于圆，你可以用“到圆心的距离为半径的点”表示圆上的点，用“到圆心的距离为半径的直线”表示切线。
