# 更新日志

## v2.5.2

- 修正打包版本号：统一为 2.5.2（v2.5.1 产物的文件名与应用内版本号仍显示 2.5.0，现已一致）
- 无功能变更，修复内容见 v2.5.1

## v2.5.1

- 修复启动白屏：启动时显示"加载中"遮罩，主界面就绪后自动消失，慢速设备不再长时间空白
- 修复删除/状态/重置对话框按钮无文字的问题
- 修复对象列表条件显示不正确：现在直接显示条件本身（如 AB⊥CD），而非背后的代数方程
- 修复删除对话框牵连对象中 LaTeX 命令（如 \perp）显示为文字的问题
- 修复旧设备（Android 9 / 低配桌面）上的显示与交互问题：弹窗关闭闪烁、顶栏标题竖排、按钮英文溢出
- 修复未知数名与坐标保留名冲突时报错文案缺失（中英双语均正常显示）

## v2.5.0

- 新增 Tauri 桌面壳：桌面端（Linux / Windows / macOS）以原生窗口运行，`tauri dev` 开发 / `tauri build` 打包
- 新增 Android 支持：可构建 APK（`tauri android build --apk --debug`），系统要求 Android 7.0（API 24）及以上，支持 arm64-v8a / armeabi-v7a / x86 / x86_64 四种架构
- 修复 Android 边缘到边缘布局：顶栏计入状态栏高度，不再被遮挡
- 修复文档页中文模式样式异常：窄屏下"原版文档 / 维护者文档"分组标签不再逐字竖排
- 主题与语言改为跟随系统：未手动设置时实时跟随系统深浅色与系统语言，手动切换后固定，「清除本地偏好」恢复跟随
- 新增一键编译工具 `build.sh`：交互式菜单 + 命令行参数双模式，支持桌面/Android/全量构建、指定架构与打包格式、产物清理、版本统一（`./build.sh help` 查看用法）

## v2.4.0

- 计算核心重写为 TypeScript 引擎（替换原 Python/SymPy 后端），全部计算在浏览器内完成，无需外部进程
- 前端直连引擎，移除桥接层；操作历史自动保存，刷新页面后一键恢复现场
- 新增角度函数 acos（如求三角形角度），符号求解优先、数值求解兜底
- 新增「重置计算器」清零功能（菜单 ☰ → 重置计算器），一键清空所有对象

## v2.2.0

- 全新前端界面（Material 3 风格，支持深浅主题与中英切换）
- 手写文档系统：按版本查看《使用指南》《关于》《更新日志》
- 历史版本的文档见 `doc/archive/{版本号}/` 目录

> 本文档会随版本持续更新；每次发布新版本时，将旧版本文档归档到
> `doc/archive/{旧版本号}/`（按 `original/`、`maintainer/` 分组），并在
> `doc/manifest.json` 的 `versions` 中登记。
